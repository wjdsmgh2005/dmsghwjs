🛡 사기 예방 필수 수칙
1선입금 절대 금지 — 상품 확인 전 절대 입금하지 마세요. 100% 사기입니다.
2에스크로 이용 — 고가 상품은 반드시 안전결제(에스크로)를 요청하세요.
3공공장소 직거래 — 편의점, 경찰서, 지하철역 등 안전한 장소에서 만나세요.
4신뢰등급 확인 — 판매자 신뢰등급이 [신규]인 경우 추가 확인을 요청하세요.
5개인정보 주의 — 계좌번호, 주민번호, 주소를 채팅으로 보내지 마세요.
6시세 확인 — 시세보다 30% 이상 저렴하면 미끼 상품일 수 있습니다.
7즉시 신고 — 사기 의심 시 즉시 이 앱에서 신고하고 경찰 112에도 신고하세요.
🚨 주요 사기 수법 가이드
1
선입금 사기 (가장 흔함)
판매자가 택배로 먼저 보내겠다며 입금을 요구합니다. 입금 후 연락이 끊깁니다.
⚠ 패턴: "먼저 입금해주시면 바로 발송할게요"
2
가품/불량 상품 교체
직거래 시 진품을 보여주고 택배로 가품이나 불량품을 발송합니다.
⚠ 패턴: "직거래 불가, 택배만 가능해요"
3
에스크로 피싱
앱 외부 가짜 안전거래 사이트로 유도하여 결제를 시킵니다.
⚠ 패턴: 외부 링크로 유도, "여기서 결제하면 더 안전해요"
4
개인정보 요구
안전거래 명목으로 신분증 사진이나 계좌정보를 요구합니다.
⚠ 패턴: "본인 확인을 위해 신분증 앞면 사진을 보내주세요"

🔒 안전결제 (에스크로)

구매자와 판매자 모두를 보호하는 중개 결제 시스템

에스크로란?

구매자가 먼저 당근나라 PC에 돈을 맡기고, 상품을 수령 확인한 후 판매자에게 지급하는 안전한 거래 방식입니다.

1
구매자 결제
구매자가 앱에 거래 금액을 예치합니다. 판매자에게 직접 전달되지 않습니다.
2
판매자 발송/직거래
구매자 예치 확인 후 판매자가 상품을 발송하거나 직거래를 진행합니다.
3
구매자 수령 확인
구매자가 상품 수령 후 이상 없음을 확인합니다. 문제 시 분쟁 신청 가능.
4
판매자 대금 수령
구매자 확인 완료 후 예치금이 판매자에게 자동 지급됩니다.
