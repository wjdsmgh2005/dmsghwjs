## 받은 질문 5개

### Q1. "왜 React Native를 선택했나요?"
**답변:** 팀원 전원이 JavaScript에 익숙하고, 6주 안에 Android + iOS를 동시에 배포해야 했기 때문입니다. Expo Managed Workflow를 사용해 환경 설정 복잡도를 최소화했습니다.
**근거 문서:** `.planning/decisions/ADR-0001-platform.md`
**평가:** 잘 답변함 ✅

---

### Q2. "화면에 보이는 데이터는 어디서 오나요?"
**답변:** Firebase Firestore에서 실시간으로 가져옵니다. `data/repositories/ProductRepository.ts`가 Firestore와 통신하고, `application/view_models/useProductList.ts`가 상태를 관리합니다.
**근거 문서:** `docs/architecture.md`
**평가:** 아키텍처 레이어 설명 보강 필요 ⚠️

---

### Q3. "지금 가장 큰 기술적 문제가 뭔가요?"
**답변:** 실시간 채팅 구현에서 Firestore onSnapshot 리스너 메모리 누수 이슈가 있었습니다. useEffect cleanup 함수로 해결했습니다.
**근거 문서:** `lessons/firestore-listener-cleanup.md`
**평가:** 잘 답변함 ✅

---

### Q4. "AI가 만든 부분이 어디까지인가요?"
**답변:** 초기 디렉토리 구조, 컴포넌트 보일러플레이트, 테스트 코드 초안을 AI가 생성했습니다. 저는 비즈니스 로직 검토, 버그 수정, 컴포넌트 스타일 조정을 직접 했습니다.
**평가:** 솔직하게 답변 ✅ (숨기지 않음)

---

### Q5. "남은 일정에서 가장 우선순위가 높은 게 뭔가요?"
**답변:** 13주차에 Should 기능(검색, 알림, 프로필) 완성 + 테스트 코드 작성이 우선입니다.
**평가:** 구체적인 수치 추가 필요 ⚠️
