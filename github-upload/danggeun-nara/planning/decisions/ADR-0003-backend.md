# ADR-0003 — 백엔드 선택

- **날짜**: 2026-05-19
- **상태**: 확정

---

## 배경

중고거래 앱의 백엔드 인프라 선택 — 사용자 인증, 상품 데이터 저장, 실시간 채팅을 지원해야 한다.

## 고려한 선택지

| 옵션 | 장점 | 단점 |
|------|------|------|
| **Firebase** | 인증+DB+스토리지 통합, 무료 티어, 실시간 지원 | 쿼리 유연성 낮음, 벤더 종속 |
| Supabase | PostgreSQL 기반, 오픈소스 | 한국 데이터센터 없음 |
| 직접 구축 (Node.js + Express) | 완전한 제어권 | 개발 시간 과다 |

## 결정

**Firebase (Firestore + Authentication + Storage)** 선택

## 이유

1. 인증(소셜 로그인), DB, 파일 저장, 실시간 채팅을 하나의 플랫폼에서 해결
2. 무료 Spark 플랜으로 MVP 운영 가능
3. React Native/Expo 공식 연동 라이브러리 존재 (`@react-native-firebase`)
4. 실시간 채팅은 Firestore onSnapshot으로 구현 가능

## 결과 & 위험

- **긍정**: 백엔드 개발 시간 절약 → 프론트 완성도에 집중 가능
- **위험**: Firestore 무료 티어 한도 (읽기 50,000/일) → 데모 범위에서 충분
- **대응**: 캐싱 레이어(React Query)로 불필요한 읽기 최소화
