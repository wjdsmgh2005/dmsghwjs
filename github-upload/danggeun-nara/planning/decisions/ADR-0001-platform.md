# ADR-0001 — 모바일 플랫폼 선택

- **날짜**: 2026-05-19
- **상태**: 확정

---

## 배경

중고거래 앱 "당근나라"의 프론트엔드 플랫폼을 선택해야 한다.
팀원 모두 JavaScript/TypeScript 경험이 있고, 동시에 Android와 iOS를 타겟해야 한다.

## 고려한 선택지

| 플랫폼 | 장점 | 단점 |
|--------|------|------|
| **React Native** | JS/TS 생태계, Expo로 빠른 시작, 커뮤니티 풍부 | 네이티브 모듈 시 복잡도 |
| Flutter | 한 코드로 양 OS, 성능 우수 | Dart 언어 학습 필요 |
| Android (Kotlin) | 완전한 네이티브 | iOS 별도 개발 필요 |

## 결정

**React Native (Expo Managed Workflow)** 선택

## 이유

1. 팀원 전원이 JavaScript에 익숙하여 학습 비용 최소화
2. Expo를 통해 환경 설정 없이 빠른 빌드 가능
3. 6주의 짧은 기간에 Android + iOS 동시 배포 필요
4. 중고거래 앱 특성상 네이티브 고성능 기능보다 UI/UX가 중요

## 결과 & 트레이드오프

- **긍정**: 빠른 프로토타이핑, 웹 개발 경험 재활용 가능
- **부정**: 복잡한 카메라/위치 기능은 Expo 제약이 있을 수 있음
- **대응**: Expo Go 범위 내에서 기능 조정, 필요 시 Expo Bare Workflow 전환
