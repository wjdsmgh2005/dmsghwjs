# ADR-0002 — 상태 관리 라이브러리 선택

- **날짜**: 2026-05-19
- **상태**: 확정

---

## 배경

React Native 앱에서 상품 목록, 사용자 정보, 채팅 상태 등 전역 상태 관리가 필요하다.

## 고려한 선택지

| 옵션 | 장점 | 단점 |
|------|------|------|
| **Zustand** | 간단한 API, 적은 보일러플레이트 | 대규모 앱에서 구조화 어려움 |
| Redux Toolkit | 강력한 DevTools, 대형 앱에 적합 | 초기 설정 복잡 |
| Context API | 별도 라이브러리 불필요 | 잦은 리렌더링 문제 |
| Jotai | 원자 단위 상태, 간결 | 커뮤니티 작음 |

## 결정

**Zustand** 선택

## 이유

1. 코드가 간결하여 초급자도 빠르게 이해 가능
2. 6주 프로젝트 규모에서 Redux의 복잡도가 불필요
3. TypeScript 지원이 우수하고 미들웨어 연동 용이

## 결과

- 전역 스토어: 사용자 인증, 상품 목록, 채팅 메시지, 관심 목록
- 로컬 상태는 컴포넌트 useState로 처리
