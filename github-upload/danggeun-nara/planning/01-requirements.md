## MoSCoW 분류

### ✅ Must Have (반드시 있어야 함)

| # | 기능 | 설명 |
|---|------|------|
| M1 | 회원가입 / 로그인 | 이메일, 소셜(카카오/네이버) 인증 |

| M4 | 상품 상세 페이지 | 사진, 설명, 판매자 정보, 가격 표시 |
| M5 | 1:1 채팅 | 구매자-판매자 실시간 채팅 |
| M6 | 관심 목록 (찜) | 상품 찜 등록/해제 |
| M7 | 판매 상태 관리 | 판매중 / 판매완료 전환 |
